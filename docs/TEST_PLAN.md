# Test Plan & Verification

## Core Test Scenarios
- **AUTH-001**: User sign up creates profile and role row.
- **APT-001**: Slot collision validation prevents overlapping double-bookings.
- **APT-002**: Patient self-cancellation releases slot for new bookings.
- **DOC-001**: Doctor confirms appointment, triggering patient notification.
- **SEC-001**: Row Level Security prevents patient from reading unauthorized medical records.
